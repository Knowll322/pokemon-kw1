# Pocket Beasts: Forest Journey

A small original 2D pixel-art mini RPG inspired by classic handheld monster-catching adventures. All creatures, names, items, map art, and story elements are original.

## Play

Open `index.html` in a browser.

Controls:

- Arrow keys or WASD: Move / navigate menus
- Z, Space, or Enter: Confirm / interact
- X, Escape, or Backspace: Back / open menu in the overworld
- Touch buttons are available on small screens

## Features

- Tile-based village, forest, cave, grass, and final arena
- Random wild creature encounters
- Turn-based battles with elemental advantages
- Beast Capsule capture system
- Six original creatures
- Three NPC trainers and one final mini-boss
- Inventory, party, level, EXP, save, and load systems
